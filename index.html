Fase 1: Pengenalan Konsep VPS & Cloud

Pemahaman mengenai perbedaan layanan hosting dan server cloud:

Shared Hosting

Layanan hosting di mana satu server fisik digunakan bersama-sama oleh banyak pengguna. Sumber daya (CPU, RAM) dibagi rata, biaya sangat murah, namun konfigurasi server sangat terbatas.

Dedicated Server

Penyewaan satu unit server fisik secara penuh untuk satu pengguna saja. Performa maksimal dan kontrol penuh, tetapi biaya sewa mahal dan membutuhkan keahlian manajemen server.

Amazon Lightsail

Layanan VPS (Virtual Private Server) dari AWS yang mudah digunakan dengan paket harga bulanan tetap, sudah mencakup penyimpanan SSD, transfer data, dan pengaturan jaringan yang sederhana.

Amazon EC2

Layanan komputasi awan (IaaS) dari AWS yang sangat fleksibel dan skalabel. Pengguna bebas mengatur spesifikasi CPU, RAM, OS, keamanan jaringan (Security Group), dengan sistem bayar sesuai pemakaian.

Fase 2: Persiapan dan Provisioning Server

  • ☑ Mengaktifkan akun AWS dan login ke Management Console.
  • ☑ Memilih Region AWS terdekat / yang tersedia (misal: us-east-1 / ap-southeast-1).
  • ☑ Memilih Amazon Machine Image (AMI), misalnya Ubuntu 22.04 LTS / Windows Server.
  • ☑ Memilih Instance Type yang sesuai (misal: t2.micro / t3.micro / t3.large).

Fase 6: Manajemen, Monitoring & Backup

Catat Metrik Server Saat Ini (CloudWatch):

  • Rata-rata CPU Utilization : 1.5 % (sesuaikan dengan grafik Monitoring di AWS Anda)
  • Status Check Failed : 0 (3/3 pemeriksaan lulus)

Langkah Backup (Snapshot):

  1. Buka menu Volumes di konsol EC2.
  2. Pilih Volume server Anda.
  3. Klik Actions > Create Snapshot.
  4. Beri deskripsi dan simpan.
